# 🏢 نظام الدورة المستندية للإدارة العامة للعقود والمشتريات
### (Procurement & Contracts Management System)

تطبيق ويب متكامل، مؤمن أمنياً (Secure with JWT & RBAC & Audit Trail)، سهل الاستخدام واحترافي مبني باستخدام **React (Frontend)**، **Node.js / Express (Backend)**، وقاعدة بيانات **Microsoft SQL Server** (مع محرك محلي فوري).

---

## 🔐 1. بيانات الدخول وحسابات الأدوار والصلاحيات (Demo Accounts)

النظام مزود بشاشة تسجيل دخول مسبقة (`/login`) وبوابة تحقق وصلاحيات لكل شاشة:

| اسم المستخدم | كلمة المرور | الدور الوظيفي (Role) | الشاشات المتاحة والصلاحيات |
| :--- | :--- | :--- | :--- |
| **`sa`** | `1` | **المشرف العام (Super Admin)** | كامل شاشات النظام، إدارة المستخدمين، الأرشيف، وسجل الرقابة |
| **`tenders_user`** | `1` | **مسؤول الطرح والمواصفات** | طلبات الاحتياج، شاشة الطرح، كراسة الشروط، التقارير |
| **`committee_user`** | `1` | **لجنة البت والتفريغ** | شاشة فض المظاريف، شاشة البت والتقييم، التقارير |
| **`finance_user`** | `1` | **المراجع المالي والإسناد** | شاشة الإسناد، إذن التوجيه، حساب الدمغات، التقارير |
| **`vendor_user`** | `1` | **مسؤول قيد الموردين** | سجل الموردين (66 مجموعة)، سجل المقاولين (1-7)، سجل الشطب |
| **`security_user`** | `1` | **المراجع الرقابي والأمني** | لوحة التحكم، سجل الأنشطة (Audit Trail)، الأرشيف |

## 🗄️ 2. المميزات والوحدات الرئيسية

1. **بوابة تسجيل الدخول الآمنة (Login Page):**
   - حماية المسارات (Protected Routes) وإدارة الجلسات برمز JWT مشفر.
   - بطاقات اختيار سريع للحسابات التجريبية بالجانب.

2. **شاشة الطرح وكراسة الشروط والمواصفات (Tendering & Booklet Pricing):**
   - استدعاء تلقائي لطلبات الاحتياج، توليد رقم العملية المسلسل (`هـ`, `ت`, `ز`...) مع تصفير سنوي بالعام المالي (6/30).
   - محرك حساب كراسة الشروط يشمل (20% إدارية، 14% مضافة، طوابع التكافل، الشهيد، والتكميل لأقرب 5 ج).

3. **شاشة فض المظاريف والتفريغ المالي والفني (Envelope Opening):**
   - فحص آلي لحالة قيد الشركات (🟢 أخضر: مسجل، 🟡 أصفر: سابقة أعمال، 🔴 أحمر: مشطوب وممنوع من التعامل مع حظر آلي).
   - ترقيم كسر العطاء التلقائي (1/5، 2/5)، تفريغ بنود المظروف المالي بالوحدات المعتمدة.

4. **شاشة البت والتقييم الفني والمالي (Evaluation & Award Decision):**
   - تقييم فني مفصل، ترتيب المقبولين تصاعدياً ومقارنتهم بالمقايسة التثمينية.

5. **شاشة الإسناد وإذن التوجيه وحساب الدمغات (Awarding & Legal Deductions):**
   - احتساب التأمين النهائي الإلزامي (5%).
   - توليد **إذن توجيه حسابي رسمي** لتحويل التأمين الابتدائي إلى نهائي.
   - حساب كافة الدمغات والاستقطاعات الرسمية (هندسية، تطبيقية، تنمية، اتساع، تشييد وبناء، تحيا مصر، شهيد، وحوالة بريدية).

6. **سجل قيد الموردين والمقاولين وسجل الشطب (Vendors & Blacklist):**
   - تصنيف الـ 66 مجموعة توريد وفئات التشييد من الأولى إلى السابعة.
   - سجل الشطب والممنوعين مع ميزة **إلغاء الشطب (Unblacklist)**.

7. **سجل الأرشيف وسلة المحذوفات (Archive & Soft Delete):**
   - مستودع آمن لجميع العناصر المحذوفة (طلبات، مناقصات، موردين) مع توثيق اسم الحاذف وتاريخ الحذف والسبب وزر **الاسترجاع الفوري (Restore)**.

8. **سجل الرقابة والنشاط الأمني (Audit Trail & Activity Log):**
   - توثيق وتسجيل دقيق لكل حركة تمت على النظام: مين عمل إيه، التوقيت بالثانية، وعنوان الـ IP.

9. **إدارة المستخدمين والصلاحيات (User Management):**
   - شاشة خاصة بالمشرف العام لإضافة موظفين جدد وتحديد أدوارهم وأقسامهم.

10. **النماذج والمخاطبات الرسمية القابلة للطباعة (Official Forms):**
    - إذن توجيه حسابي، أمر توريد، مذكرة التأمينات (السبع بنات)، إخطار الضرائب، نموذج القوى العاملة، وتسليم ملف المخازن.

## 🚀 تشغيل النظام

### 1. تشغيل الـ Backend Server:
```bash
cd server
npm start
```
* يعمل السيرفر على: `http://localhost:5000`

### 2. تشغيل الـ Frontend React:
```bash
cd client
npm run dev
```
* تعمل الواجهة على: `http://localhost:3000`
